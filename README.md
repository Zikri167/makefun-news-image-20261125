A program that draws a newspaper front page summing up the world's news of Wednesday 25 November 2026 in one image: Ukraine confirms the Sparta II ship strike, Houthis hit Riyadh's tower, Trump pardons the Thanksgiving turkeys, the Russian war dead pass 700,000, Huawei is convicted of stealing trade secrets, plus an IN BRIEF strip — drawn procedurally with Python 3.13 stdlib only (own bitmap font + PNG encoder, no network, deterministic).

## Run it

```sh
python3 main.py
```

The program writes the front page to `/output/entry.png` (1024x1024 PNG, under 1 MiB). Set `MAKEFUN_OUTPUT_DIR` to write elsewhere, e.g. `MAKEFUN_OUTPUT_DIR=out python3 main.py`.
